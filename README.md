## 🔨 Building Now

**ESP32-S3 triple-screen homelab dashboard** (open source)
Three 2.8" TFT displays on one ESP32-S3, pulling live data from my own network.

| Screen | Shows |
|---|---|
| 1 · Network | Firewall throughput, WAN up/down, DNS queries blocked, Tailscale peers |
| 2 · Server | CPU/RAM/temp, per-pool disk usage, Docker status, Jellyfin now-playing |
| 3 · TBD | Open slot |

Stack: `ESP-IDF` `FreeRTOS` `C`

## 🧪 Homelab

```
ISP ─► Sophos XG135 ─┬─► Lenovo tiny PC  (OMV · Docker · Jellyfin · Samba)
                     ├─► OpenWRT router  (AdGuard · Tailscale)
                     ├─► CCTV
                     └─► AP router
```

- NAS: mirrored SSDs + HDD pool + backup HDD, Cryptomator-encrypted at rest
- Private remote access over Tailscale, DNS filtering via AdGuard
- Segmented per-interface zones on the firewall
